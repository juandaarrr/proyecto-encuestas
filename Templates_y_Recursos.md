## 🎓 TEMPLATE 6: CAPACITACIÓN PARA LÍDERES (Cómo usar los datos)

```
GUÍA RÁPIDA: Usando los Datos de Onboarding

PARA LÍDERES DE DEPARTAMENTO

1. ACCEDER AL DASHBOARD
   - URL: [PEGAR LINK DATA STUDIO]
   - Actualización: Automática (tiempo real)

2. INTERPRETAR LOS DATOS

   ✅ Puntuación BUENA (4-5):
      → Seguir igual, excelente proceso
      → Compartir como modelo con otros departamentos

   ⚠️ Puntuación MEDIA (2.5-3.5):
      → Hay mejoras por hacer
      → Contactar al colaborador para entender dificultades

   ❌ Puntuación CRÍTICA (<2.5):
      → Acción inmediata requerida
      → Escaltar a RH

3. PREGUNTAS CLAVE A RESPONDER

   Por departamento:
   ✓ ¿Cuál es la puntuación promedio?
   ✓ ¿Hay áreas consistentemente bajas?
   ✓ ¿Necesitamos más capacitación en algo específico?
   ✓ ¿Las herramientas están disponibles desde el día 1?

4. ACCIONES POR PUNTUACIÓN

   Si Integración Cultural < 3.5:
   → Mejorar actividades de team building
   → Facilitar conexiones con otros departamentos
   → Comunicar cultura y valores más explícitamente

   Si Integración Operativa < 3.5:
   → Revisar checklist de provisión de herramientas
   → Crear guía de procesos más clara
   → Asignar mentor/buddy

5. PRÓXIMOS PASOS
   → Revisar datos semanalmente
   → Contactar casos críticos
   → Reportar mejoras a RH
```
