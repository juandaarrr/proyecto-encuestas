```
1. Lee RESUMEN_EJECUTIVO_RAPIDO.md (5 min)
   → Entiende el proyecto en la nutshell

   → Aprende QUÉ estamos mediendo y POR QUÉ

3. Decide si procedes o tienes preguntas
```

### Escenario 2: "Voy a empezar implementación"
```
1. Abre Cronograma_e_Implementacion.md
   → Busca la sección CHECKLIST SEMANA 1

2. Abre Paso_a_Paso_Implementacion.md
   → Sigue PASO 1: Crear Google Form

3. Ve cumpliendo checkboxes según avanzas

4. Consulta Templates_y_Recursos.md cuando necesites emails
```

### Escenario 3: "Ya está en operación"
```
1. Cada VIERNES → Consulta Cronograma > MONITOREO SEMANAL
   → Revisa qué debes hacer esa semana

2. Cada 15 DÍAS → Sigue ANÁLISIS QUINCENAL
   → Reúnete con equipo, revisa tendencias

3. Cada FIN DE MES → Consulta Templates > TEMPLATE 4
   → Genera reporte ejecutivo

4. Si problema → Consulta Paso_a_Paso > TROUBLESHOOTING
```
