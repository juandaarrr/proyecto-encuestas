# 📋 ENCUESTA DE EVALUACIÓN DE ADAPTACIÓN - PERSPECTIVA DEL JEFE/LÍDER
## Providencia S.A. — Formulario Independiente para Jefes de Área/Zona

**Objetivo**: Que el jefe directo evalúe el proceso real de adaptación técnica y cultural del colaborador nuevo, desde su observación directa como líder.

**Diferencia clave con la encuesta del colaborador**: Esta encuesta la responde el JEFE, no el nuevo ingreso. Es un formulario **totalmente independiente** — otra URL, otra hoja de cálculo, otro dashboard.

**Metodología**: Igual que la encuesta anterior — preguntas observacionales e indirectas, no calificaciones directas tipo "califica del 1 al 10 a tu colaborador", que generan respuestas sesgadas o complacientes.

**Tiempo estimado**: 5-6 minutos

---

## 🎯 FILOSOFÍA DE LAS PREGUNTAS (Perspectiva Líder)

Un jefe tiende a responder positivamente por defecto si se le pregunta directo ("¿está bien integrado?"). Por eso estas preguntas buscan **evidencia observable de comportamiento**, no opinión general:

- ❌ "¿El colaborador está bien integrado?"
- ✅ "¿Qué tan seguido debes repetir instrucciones o corregir la misma situación?"

- ❌ "¿Recibió buena inducción?"
- ✅ "¿En cuánto tiempo empezó a ejecutar tareas sin supervisión constante?"

- ❌ "¿Se lleva bien con el equipo?"
- ✅ "¿Has notado que otros miembros del equipo lo integran espontáneamente en tareas o conversaciones?"

---

## 📝 ESTRUCTURA

```
SECCIÓN 1: DATOS DE CONTEXTO (5 preguntas)
    └─ Identifica jefe, colaborador evaluado, tiempo de relación

SECCIÓN 2: OBSERVACIÓN TÉCNICA/OPERATIVA (6 preguntas - Escala 1-5)
    └─ Autonomía real observada, curva de aprendizaje, calidad de base técnica

SECCIÓN 3: OBSERVACIÓN CULTURAL/RELACIONAL (6 preguntas - Escala 1-5)
    └─ Comportamiento en equipo, receptividad, integración espontánea

SECCIÓN 4: REVELADORES CLAVE - ALERTAS Y FORTALEZAS (4 preguntas abiertas)
    └─ Espacio para lo que no cabe en una escala
```

# ✅ PREGUNTAS FINALES

## 📍 SECCIÓN 1: DATOS DE CONTEXTO

### Pregunta 1: Nombre del Jefe/Líder
```
Tipo: Respuesta corta
Pregunta: "¿Cuál es tu nombre completo?"
Obligatoria: SÍ
```

### Pregunta 2: Correo del Jefe/Líder
```
Tipo: Respuesta corta (texto)
Pregunta: "¿Cuál es tu correo empresarial?"
Obligatoria: SÍ
```

### Pregunta 3: Nombre del Colaborador Evaluado
```
Tipo: Respuesta corta
Pregunta: "¿Cuál es el nombre completo del colaborador que estás evaluando?"
Obligatoria: SÍ
```

### Pregunta 4: Departamento/Área/Zona
```
Tipo: Opción múltiple (una respuesta)
Pregunta: "¿A qué departamento, área o zona pertenece el colaborador evaluado?"
Opciones:
  • Recursos Humanos
  • Operaciones
  • Comercial/Ventas
  • Tecnología
  • Administración
  • Servicios al Cliente
  • Logística
  • Otro (especificar)
Obligatoria: SÍ
```

### Pregunta 5: Tiempo Trabajando Directamente con el Colaborador
```
Tipo: Opción múltiple (una respuesta)
Pregunta: "¿Hace cuánto tiempo supervisas o trabajas directamente con este colaborador?"
Opciones:
  • Menos de 2 semanas
  • 2 a 4 semanas
  • 1 a 2 meses
  • 2 a 3 meses
  • Más de 3 meses
Obligatoria: SÍ

🔍 QUÉ REVELA: Contextualiza la validez de la observación —
   una evaluación con 2 semanas de trato tiene menos peso
   que una con 2-3 meses.
```

## 🔧 SECCIÓN 2: OBSERVACIÓN TÉCNICA/OPERATIVA

### Pregunta 6: AUTONOMÍA REAL OBSERVADA
```
Tipo: Escala lineal 1-5
Pregunta: "¿En cuánto tiempo notaste que el colaborador empezó a ejecutar 
          tareas de su rol sin necesitar supervisión constante?"
Etiqueta 1: "Aún requiere supervisión constante"
Etiqueta 5: "Desde la primera o segunda semana"
Obligatoria: SÍ

🔍 QUÉ REVELA: Velocidad real de la curva de aprendizaje,
   vista desde afuera (más objetiva que la autopercepción)
```

### Pregunta 7: CAPACIDAD DE RESOLVER SIN INTERVENCIÓN
```
Tipo: Escala lineal 1-5
Pregunta: "Si mañana le asignas una tarea nueva pero similar a las que 
          ya maneja, ¿qué tan seguro estás de que la resolvería 
          correctamente sin que intervengas?"
Etiqueta 1: "Nada seguro, necesitaría guiarlo paso a paso"
Etiqueta 5: "Totalmente seguro, la resolvería solo"
Obligatoria: SÍ

🔍 QUÉ REVELA: Confianza técnica real del líder,
   proyección a futuro de independencia
```

### Pregunta 8: MANEJO DE ERRORES
```
Tipo: Escala lineal 1-5
Pregunta: "Cuando el colaborador comete un error operativo, ¿qué tan 
          rápido identifica la causa y lo corrige por iniciativa propia 
          (sin que tengas que decírselo)?"
Etiqueta 1: "No lo identifica, necesita que se lo señalen"
Etiqueta 5: "Lo detecta y corrige él mismo, rápido"
Obligatoria: SÍ

🔍 QUÉ REVELA: Nivel de comprensión real del proceso
   (no memorización superficial)
```

### Pregunta 9: REPETICIÓN DE INSTRUCCIONES
```
Tipo: Escala lineal 1-5
Pregunta: "¿Qué tan seguido te encuentras repitiendo la misma instrucción 
          o corrigiendo la misma situación con este colaborador?"
Etiqueta 1: "Muy seguido, parece no quedar claro"
Etiqueta 5: "Casi nunca, con explicarlo una vez basta"
Obligatoria: SÍ

🔍 QUÉ REVELA: Efectividad real de la capacitación inicial
   (si hay que repetir mucho, la inducción no caló)
```

### Pregunta 10: BASE TÉCNICA AL LLEGAR
```
Tipo: Escala lineal 1-5
Pregunta: "Más allá de lo que tú personalmente le has enseñado, ¿qué 
          tan preparado en herramientas y sistemas llegó el colaborador 
          desde el proceso de inducción inicial?"
Etiqueta 1: "Llegó sin nada, tuve que enseñarle todo desde cero"
Etiqueta 5: "Llegó bien preparado, solo ajustes menores"
Obligatoria: SÍ

🔍 QUÉ REVELA: Calidad del onboarding técnico ANTES de
   llegar al área (responsabilidad de RH/IT, no del jefe)
```

### Pregunta 11: CURVA DE APRENDIZAJE COMPARATIVA
```
Tipo: Escala lineal 1-5
Pregunta: "Comparado con el tiempo que consideras estándar para dominar 
          las funciones básicas de este cargo, ¿cómo ubicarías el ritmo 
          de aprendizaje de este colaborador?"
Etiqueta 1: "Mucho más lento de lo esperado"
Etiqueta 5: "Más rápido de lo esperado"
Obligatoria: SÍ

🔍 QUÉ REVELA: Benchmark relativo, útil para detectar
   casos atípicos (muy por debajo o muy por encima)
```

## 💼 SECCIÓN 3: OBSERVACIÓN CULTURAL/RELACIONAL

### Pregunta 12: REACCIÓN A CAMBIOS Y DECISIONES DE EQUIPO
```
Tipo: Escala lineal 1-5
Pregunta: "Cuando hay un cambio de prioridades o una decisión del equipo 
          con la que quizás no está totalmente de acuerdo, ¿cómo 
          reacciona generalmente?"
Etiqueta 1: "Se resiste o lo cuestiona de forma poco constructiva"
Etiqueta 5: "Se adapta con buena actitud, pregunta si tiene dudas"
Obligatoria: SÍ

🔍 QUÉ REVELA: Flexibilidad cultural real, no solo
   obediencia superficial
```

### Pregunta 13: PARTICIPACIÓN INFORMAL
```
Tipo: Escala lineal 1-5
Pregunta: "¿Qué tan involucrado se muestra el colaborador en las 
          dinámicas informales del equipo (conversaciones de pasillo, 
          pausas, chats grupales, actividades)?"
Etiqueta 1: "Se mantiene al margen, poco participativo"
Etiqueta 5: "Participa activamente, se le ve cómodo"
Obligatoria: SÍ

🔍 QUÉ REVELA: Nivel real de comodidad social,
   no solo cumplimiento de tareas
```

### Pregunta 14: CONFIANZA PARA ACUDIR AL LÍDER
```
Tipo: Escala lineal 1-5
Pregunta: "Si el colaborador tuviera una duda incómoda, un desacuerdo o 
          una dificultad personal que afecta su trabajo, ¿qué tan 
          probable es que te lo cuente a ti directamente antes que 
          a alguien más?"
Etiqueta 1: "Poco probable, prefiere evitar ese tipo de conversación"
Etiqueta 5: "Muy probable, ya lo ha hecho o percibo esa confianza"
Obligatoria: SÍ

🔍 QUÉ REVELA: Calidad real de la relación de confianza
   líder-colaborador (clave para retención)
```

### Pregunta 15: INTEGRACIÓN ESPONTÁNEA POR PARES
```
Tipo: Escala lineal 1-5
Pregunta: "¿Has notado que otros miembros del equipo lo incluyen 
          espontáneamente en tareas, conversaciones o decisiones, 
          sin que tú tengas que pedírselos?"
Etiqueta 1: "No, sigue siendo tratado como 'el nuevo'"
Etiqueta 5: "Sí, ya lo integran naturalmente como uno más"
Obligatoria: SÍ

🔍 QUÉ REVELA: Aceptación real por parte del grupo
   (más objetiva que la autopercepción del colaborador)
```

### Pregunta 16: RECEPTIVIDAD A RETROALIMENTACIÓN
```
Tipo: Escala lineal 1-5
Pregunta: "Cuando le das retroalimentación (positiva o de mejora), 
          ¿cómo reacciona generalmente?"
Etiqueta 1: "A la defensiva o le cuesta recibirla"
Etiqueta 5: "La recibe bien y la aplica"
Obligatoria: SÍ

🔍 QUÉ REVELA: Madurez profesional y apertura al
   crecimiento, indicador de éxito a largo plazo
```

### Pregunta 17: ALINEACIÓN CON LA FORMA DE TRABAJAR DEL ÁREA
```
Tipo: Escala lineal 1-5
Pregunta: "¿Qué tan alineadas percibes las prioridades y forma de 
          trabajar del colaborador con la manera en que se hacen 
          las cosas en tu área?"
Etiqueta 1: "Percibo choques o formas de trabajo muy distintas"
Etiqueta 5: "Está muy alineado con la dinámica del área"
Obligatoria: SÍ

🔍 QUÉ REVELA: Fit cultural específico al equipo
   (más allá de los valores generales de la empresa)
```

## 🎯 SECCIÓN 4: REVELADORES CLAVE (Preguntas Abiertas)

### Pregunta 18: FORTALEZA IDENTIFICADA
```
Tipo: Respuesta larga (párrafo)
Pregunta: "¿Qué fortaleza específica has notado en este colaborador 
          durante su proceso de adaptación?"
Obligatoria: NO

🔍 QUÉ REVELA: Fortalezas reales a reforzar y potencialmente
   replicar en el proceso de selección
```

### Pregunta 19: ALERTA O DIFICULTAD
```
Tipo: Respuesta larga (párrafo)
Pregunta: "¿Hay alguna dificultad, alerta o situación con este 
          colaborador que consideres importante que RH conozca?"
Obligatoria: NO

🔍 QUÉ REVELA: Riesgos tempranos no capturados en las escalas,
   posibles casos de atención prioritaria
```

### Pregunta 20: MEJORA AL PROCESO DE INDUCCIÓN
```
Tipo: Respuesta larga (párrafo)
Pregunta: "Si pudieras cambiar algo del proceso de inducción que 
          recibió este colaborador antes de llegar a tu equipo, 
          ¿qué sería?"
Obligatoria: NO

🔍 QUÉ REVELA: Retroalimentación operativa directa para
   mejorar el onboarding desde la óptica de quien recibe
   al colaborador ya "entrenado"
```

### Pregunta 21: SÍNTESIS EN UNA FRASE
```
Tipo: Respuesta corta
Pregunta: "En una frase, ¿cómo describirías el nivel de adaptación 
          actual de este colaborador?"
Obligatoria: NO

🔍 QUÉ REVELA: Percepción general sintetizada, útil para
   lectura rápida en reportes ejecutivos
```

```
2.1 - 3.0: DÉBIL - Integración superficial, aún "el nuevo"
3.1 - 3.9: REGULAR - Aceptación en curso
4.0 - 5.0: FUERTE - Integración cultural exitosa
```

## 🔗 CRUCE CON LA ENCUESTA DEL COLABORADOR

**Este es el verdadero valor**: comparar la autopercepción del colaborador (encuesta 1) contra la observación del jefe (encuesta 2), usando el nombre del colaborador como llave de cruce (Pregunta 1 de la encuesta 1 = Pregunta 3 de esta encuesta).

```
CASO A: Colaborador se autoevalúa alto + Jefe evalúa alto
  → Integración exitosa confirmada desde ambos ángulos ✅

CASO B: Colaborador se autoevalúa alto + Jefe evalúa bajo
  → Punto ciego: el colaborador no percibe sus brechas reales
  → Acción: feedback directo y honesto del líder

CASO C: Colaborador se autoevalúa bajo + Jefe evalúa alto
  → Síndrome del impostor / falta de confianza propia
  → Acción: refuerzo positivo, mentoría de confianza

CASO D: Colaborador se autoevalúa bajo + Jefe evalúa bajo
  → Alerta crítica confirmada desde ambos ángulos 🚩
  → Acción: intervención inmediata de RH
```

Esta comparación es mucho más potente que cualquiera de las dos encuestas por separado.
